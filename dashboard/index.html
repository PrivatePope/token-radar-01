How the radar values a token

implied = TVL0.8 × 8 × (1 + 0.9 × clamp(7d%, −50..+150)) × (0.6 + 0.7 × min(age, 1460) ÷ 1460) × (1 + 0.015 × min(chains, 10))

Three signals from the snapshot, and nothing else. Size: total value locked, raised to 0.8 so a protocol twice as big is not worth twice as much. Momentum: the last seven days’ TVL change, clamped to −50%..+150% so one wild week cannot decide a rank. Patience: how many days the protocol has run with no token, up to four years — a launch that has waited is worth more than one that appeared yesterday. A protocol with no listing date takes the median age of the pre-token set (513 days); a missing seven-day change counts as zero.

No protocol name is special-cased. Every input is a figure from the snapshot, the same function scores every row, and the board is the whole pre-token set the house rule admits — not a hand-picked list.
